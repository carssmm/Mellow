# Mellow Café System

> **A modern, lightweight POS, Inventory, and Profit Tracking application designed for independent café operators.**

## ☕ Key Features

- **⚡ Quick Tap POS:** High-speed touchscreen point-of-sale interface optimized for fast-paced rush hours with multi-payment support (Cash, GCash, Maya).
- **📦 Dual-Unit Inventory Management:** Track inventory in both individual pieces and bulk packages (boxes, cases, packs) with automatic unit cost calculation.
- **📊 Sales & COGS Analytics:** Real-time revenue, Cost of Goods Sold (COGS), net profit tracking, top-selling product rankings, and CSV reporting exports.
- **💵 Cash Register Reconciliation:** Track opening floats, cash drawer balances, and calculate daily overages/shortages automatically.
- **🎯 Daily Breakeven Tracker:** Visual target progress bar helping owners stay on track to reach daily revenue and profit goals.

---

## 🛠 Tech Stack & Architecture

- **Framework:** Next.js 15 (App Router with Server Actions)
- **Database & Authentication:** Supabase (PostgreSQL with Row-Level Security for multi-tenancy)
- **Form Validation:** Zod + React Hook Form
- **UI & Styling:** Tailwind CSS v4, Lucide React Icons

## 🚀 Quick Start

### 1. Prerequisites
- Node.js 18.x or later
- npm or pnpm
- Supabase project credentials

### 2. Environment Setup
Copy `.env.example` to `.env.local` and add your Supabase credentials:

```bash
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### 3. Database Migration
Run the migration scripts located in `supabase/migrations/` on your Supabase SQL editor:
1. `001_initial_schema.sql`
2. `002_add_package_costing.sql`

### 4. Development Server
Install dependencies and launch the dev server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
