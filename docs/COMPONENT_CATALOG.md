## Design System Tokens & Badges

### Stock Status Badges
- **In Stock** (`current_stock > low_stock_threshold`): Green badge (`bg-emerald-100 text-emerald-800 border-emerald-300`)
- **Low Stock** (`0 < current_stock <= low_stock_threshold`): Amber warning badge (`bg-amber-100 text-amber-800 border-amber-300`)
- **Out of Stock** (`current_stock <= 0`): Red badge (`bg-rose-100 text-rose-800 border-rose-300`)
